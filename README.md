# optical-flow-for-obstacle-detection

Обнаружение препятствий для БПЛА по фронтальной камере на основе оптического потока
(дипломная работа, МГУ, ВМК, кафедра НДСиПУ).

Детектор считает плотный оптический поток (Farneback), по дивергенции поля оценивает время до
столкновения (TTC = 2 / div), выделяет область препятствия на линии полёта и выдаёт манёвр:
облёт слева, справа или остановка. Для реального полёта добавлены компенсация поворота по
ориентации дрона, маска пола по горизонту и вычитание фона строки.

## Структура

```
code/
  common/          типы, источники кадров, разметка, метрики, отрисовка, UZH-FPV и TUM
  optical_flow/    детектор, бэкенды потока, синтетические сцены, подбор параметров, демо
    presets.json   итоговые настройки и их результаты на полётах в ангаре
  neural_net/      нейросетевой метод (в работе)
  data/            только ручная разметка (*.events.json, *.labels.csv); сами данные не хранятся
  real_videos.py   проверка на реальных видео: листы кадров, оценка, демо
  run_live.py      живой запуск на вебкамере
  run_bench.py     замеры на видео и датасетах
figures/           схема метода и графики
```

Подробно о коде и запуске: [code/README.md](code/README.md).

## Установка

```
cd code
python -m venv .venv
.venv\Scripts\activate        # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

## Данные (не входят в репозиторий)

- **UZH-FPV Drone Racing** (полёты indoor_forward_3, 6, 9, 10 и outdoor_forward_1, версия Snapdragon with GT):
  https://fpv.ifi.uzh.ch/datasets/ — распаковать в `code/data/uzh_fpv/<имя>/`, затем
  `python data/uzh_fpv/to_video.py <имя>`.
- **TUM RGB-D**, freiburg2_pioneer_slam: https://cvg.cit.tum.de/data/datasets/rgbd-dataset — в `code/data/tum/`.
- Синтетические сцены генерируются скриптом `optical_flow/render_cache.py`.

## Основные результаты (полёты в ангаре UZH-FPV, настройка `hangar_gyro`)

| полёты | опасные подлёты пойманы | ложные тревоги на открытом пути |
|---|---|---|
| 3 и 6 (подбор параметров) | 21/21 | 3.8 % |
| 9 и 10 (проверка) | 3/3 | 0.9 % |

Время обработки около 8 мс на кадр (Ryzen 5 7535HS, один поток).
